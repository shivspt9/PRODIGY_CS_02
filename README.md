# ImageEncryptor

**ImageEncryptor** is a lightweight Python tool for simple image encryption and decryption using pixel value manipulation. This project is intended for educational and illustrative purposes in image processing and basic cryptography.

## Features

- **Encrypt** and **decrypt** image files using a numeric key
- Works with any image format supported by Pillow (e.g., PNG, JPEG)
- Clean and simple CLI interface
- Includes basic error handling and logging
